# Шаблон записи журнала

Скопировать в `04-logs/YYYY-MM-DD.md` (если файл за сегодня уже есть — дописать в конец новый раздел).

```markdown
# YYYY-MM-DD — краткое название задачи

**Статус:** `active | done | blocked`

## Контекст

Что попросили или что сломалось. Одно-два предложения.

## Действия

1. Шаг — команда или правка.
2. Шаг — что изменилось в файлах.
3. Шаг — проверка.

## Проверено

- [ ] `npm run build` проходит;
- [ ] страница открывается по <http://localhost:5173/>;
- [ ] изменения видны в браузере.

## Открытые вопросы

1. ...

## Следующие шаги

- ...
```
