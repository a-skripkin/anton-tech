# Стек

## Основное

| Пакет | Версия | Роль |
| --- | --- | --- |
| `react` | 19.3.1 | UI-библиотека |
| `react-dom` | 19.3.1 | Рендер в DOM |
| `vite` | 8.3.x | Dev-сервер и сборка |
| `typescript` | ~7.0.2 | Типизация |
| `@vitejs/plugin-react` | 6.1.x | JSX, Fast Refresh |
| `oxlint` | 1.90.x | Линтер |
| `react-markdown` | 10.x | Рендер Markdown в веб-версии вики |
| `remark-gfm` | 4.x | GitHub-расширения Markdown: таблицы, чек-листы |

Вспомогательное: `@types/react`, `@types/react-dom`, `@types/node`.

## Почему так

- **Vite** — запуск за доли секунды, HMR, готовый шаблон React+TS, простая статическая сборка в `dist/`.
- **React + TypeScript** — контент описывается объектами, легко расширять компонентами и типами.
- **Без UI-библиотек и CSS-фреймворков** — визитка не требует Tailwind/MUI; чистый CSS даёт полный контроль над весом и внешним видом.
- **oxlint** — быстрый линтер из шаблона create-vite, не требует отдельной настройки ESLint.
- **react-markdown + remark-gfm** — вики рендерится из тех же `.md` файлов, без второй копии контента и без самописного парсера.

Полное обоснование: [ADR 0001](../05-decisions/0001-vite-react-ts.md).

## Скрипты

| Команда | Действие |
| --- | --- |
| `npm run dev` | dev-сервер с HMR |
| `npm run build` | проверка типов (`tsc -b`) + сборка |
| `npm run preview` | локальный просмотр `dist/` |
| `npm run lint` | oxlint |

## Ограничения

- Node.js 24+ (проверено на `v24.16.0`), npm 11+.
- Версия зафиксирована в `.nvmrc` и `engines` в `package.json`; при несовпадении `npm ci` предупредит.
- Пакеты ставятся из npm, lock-файл — `package-lock.json`.
- Внешних CDN и шрифтов нет: только системные шрифты, поэтому страница работает офлайн.
