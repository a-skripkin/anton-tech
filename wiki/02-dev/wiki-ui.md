# Веб-версия вики

Вики доступна прямо на сайте: **<http://localhost:5173/#/wiki>**.

## Как устроено

- Markdown-файлы из `wiki/` импортируются как сырой текст (`?raw`) — единый источник правды, отдельной копии контента нет.
- Каталог страниц — `src/wiki/config.ts`: slug, заголовок, путь к файлу, раздел.
- Рендер — `react-markdown` + `remark-gfm` (таблицы, списки задач, зачёркивание).
- Навигация — hash-роутинг, поэтому работает на любом статическом хостинге без настройки rewrite-правил.

## Маршруты

| Адрес | Что открывается |
| --- | --- |
| `#/` | визитка |
| `#/wiki` | главная вики (`wiki/README.md`) |
| `#/wiki/<slug>` | конкретная страница, например `#/wiki/dev-server` |

Неизвестный slug безопасно открывает главную страницу.

## Как добавить страницу

1. Создать файл в `wiki/` (например, `02-dev/deploy.md`).
2. В `src/wiki/config.ts` добавить импорт:

   ```ts
   import deploy from '../../wiki/02-dev/deploy.md?raw'
   ```

3. Добавить запись в массив `wikiPages`:

   ```ts
   {
     slug: 'deploy',
     title: 'Деплой',
     file: '02-dev/deploy.md',
     group: 'Разработка',
     content: deploy,
   },
   ```

4. Раздел (`group`) должен быть из списка `groupOrder`, иначе страница не попадёт в меню.
5. Проверить `npm run build`.

## Ссылки внутри Markdown

Относительные ссылки (`../03-design/ui-kit.md`, `04-logs/`) автоматически преобразуются в маршруты вики через `resolveWikiLink`:

- `..`/`.` нормализуются;
- ссылка на папку ведёт на первую страницу раздела;
- расширение `.md` можно указывать или опускать;
- якоря (`#section`) отбрасываются.

Если файл не найден в каталоге, ссылка рендерится как текст с пунктирным подчёркиванием и подсказкой — «мёртвых» переходов нет.

Внешние ссылки (`http`, `mailto`) открываются в новой вкладке.

## Компоненты

| Файл | Роль |
| --- | --- |
| `src/wiki/config.ts` | каталог страниц, группировка, резолвер ссылок |
| `src/wiki/WikiPage.tsx` | разметка страницы, навигация, pager, мобильное меню |
| `src/wiki/WikiPage.css` | стили вики и типографика Markdown |

## Особенности

- Двухколоночный макет: липкое меню слева, контент справа.
- На экранах ≤ 900px меню превращается в выдвижную панель с затемнением.
- Внизу статьи — переходы «Предыдущая / Следующая» в порядке каталога.
- Кнопка «Наверх» и сброс скролла при смене страницы.
- Стили Markdown изолированы классом `.md`, чтобы глобальные сбросы визитки не ломали списки и заголовки.
- Поддержка `prefers-reduced-motion`.

## Ограничения

- Нет полнотекстового поиска (при 15 страницах не нужен).
- Заголовки не имеют собственных якорей: ссылки вида `#section` игнорируются.
- Контент попадает в JS-бандл при сборке; при росте вики стоит перейти на `import.meta.glob` с ленивой загрузкой.
