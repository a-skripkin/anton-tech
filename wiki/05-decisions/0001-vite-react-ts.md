# ADR 0001 — Vite + React + TypeScript для визитки

- **Дата:** 2026-11-23
- **Статус:** принято

## Контекст

Нужна простая страница-визитка: имя, роль, описание, навыки, контакты. Требования — быстрый старт, современный внешний вид, простое развитие и возможность быстро поднять локально.

## Решение

Использовать **Vite 8 + React 19 + TypeScript**, шаблон `react-ts` из `create-vite`. Стили — обычный CSS без UI-библиотек и CSS-фреймворков.

## Почему

- **Скорость:** dev-старт за ~0.3 с, HMR, сборка ~0.2 с на таком объёме.
- **Типы:** контент описывается объектами — TypeScript ловит опечатки в данных и пропсах.
- **Гибкость:** карточку легко расширить новыми секциями без переписывания.
- **Малый вес:** нет лишних зависимостей, итоговый JS ~70 kB gzip вместе с React.
- **Стандартность:** структура и скрипты знакомы любому разработчику, легко передать проект.

## Альтернативы

| Вариант | Почему не выбран |
| --- | --- |
| Чистый HTML/CSS | нет компонентов и типов, сложнее расширять |
| Next.js | SSR/маршрутизация избыточны для одной страницы |
| Astro | отличный вариант для статики, но React-навыки и интерактив здесь важнее |
| Tailwind CSS | для одной карточки хватает обычного CSS, меньше конфигурации |
| Vue/Svelte | нет причин менять привычный стек |

## Последствия

**Плюсы:** быстрая разработка, типизированный контент, статическая сборка `dist/` для любого хостинга.

**Минусы:** для SEO-критичного сайта понадобится предрендер; при росте проекта придётся добавлять роутинг и state-менеджмент.

## Когда пересмотреть

- появление нескольких страниц (кейсы, блог);
- необходимость SSR или генерации OG-страниц на сервере;
- рост числа зависимостей, требующий строгой системы стилей.
