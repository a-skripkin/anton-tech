# Глоссарий

| Термин | Значение |
| --- | --- |
| **Визитка** | Одностраничный сайт с именем, ролью, описанием и контактами. |
| **MVP** | Минимальная работающая версия: страница собирается, запускается и корректно отображается. |
| **Vite** | Сборщик и dev-сервер с мгновенным горячим обновлением (HMR). |
| **HMR** | Hot Module Replacement — обновление модуля в браузере без перезагрузки страницы. |
| **ADR** | Architecture Decision Record — короткая запись о принятом техническом решении и его причинах. |
| **Токен дизайна** | Именованное значение (цвет, отступ, радиус), используемое повторно в стилях. |
| **Стеклянная карточка** | Приём оформления: полупрозрачный фон + `backdrop-filter: blur()` + тонкая светлая рамка. |
| **Gradient text** | Текст с градиентной заливкой через `background-clip: text`. |
| **Reduced motion** | Системная настройка пользователя, отключающая лишние анимации. |
