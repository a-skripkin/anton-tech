# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [0.3.0] — 2026-11-23

### Добавлено

- Git-репозиторий в корне проекта, первый коммит `093c5b7` (ветка `main`, 37 файлов).
- `.gitattributes`: нормализация переводов строк (LF), бинарные типы.
- `start.ps1` — запуск одной командой: проверка Node, `npm ci` при отсутствии `node_modules`, открытие браузера, Vite на 5173.
- `.nvmrc` (Node 24) и `engines` в `package.json` (node ≥ 24, npm ≥ 11).
- Страница вики [«Восстановление»](02-dev/recovery.md): сценарии, git-команды, внешняя копия, чек-лист.

### Изменено

- Версия проекта в `package.json` — `0.3.0`.
- README: запуск через `.\start.ps1`.
- Вики: 16 страниц, обновлены статус, структура и стек.
- Удалены неиспользуемые ассеты шаблона create-vite (`src/assets/*`, `public/icons.svg`).

### Проверено

- `npm run build` — успешно.
- `.\start.ps1 -Port 5174 -NoOpen` — сервер поднялся, HTTP 200.
- `git status` — рабочее дерево чистое после коммита.

## [0.2.0] — 2026-11-23

### Добавлено

- Веб-версия вики: маршрут `#/wiki` и страницы `#/wiki/<slug>`.
- Каталог страниц `src/wiki/config.ts`: 15 страниц, 9 разделов, группировка для меню.
- Рендер Markdown через `react-markdown` + `remark-gfm`: заголовки, таблицы, списки задач, блоки кода.
- Автоматическое преобразование относительных ссылок между `.md` файлами в маршруты вики.
- Двухколоночный макет вики: липкое меню, хлебные крошки, переходы «предыдущая/следующая», кнопка «Наверх».
- Мобильная версия: выдвижное меню с затемнением (≤ 900px).
- Ссылка «Вики →» в подвале визитки.
- Страница документации [«Веб-версия вики»](02-dev/wiki-ui.md).

### Изменено

- `src/App.tsx`: hash-роутинг между визиткой и вики.
- `README.md` проекта: ссылки на вики и маршрут `/wiki`.
- Разделы «Стек», «Структура», «О проекте» дополнены сведениями о веб-вики.

### Проверено

- `npm run build` — успешно, 285 модулей, JS 438.07 kB (gzip 135.23 kB).
- Headless Chrome: главная вики, страница «Структура файлов» и «Правила ведения» рендерятся; битых ссылок — 0; чек-листы и таблицы на месте.

## [0.1.0] — 2026-11-23

### Добавлено

- Проект `anton-tech` на Vite 8 + React 19 + TypeScript 7.
- Страница-визитка: шапка с аватаром и статусом, имя, роль, описание, навыки, три контакта, подвал.
- Тёмная тема: градиентные подсветки, стеклянная карточка, фоновая сетка.
- Анимации: появление карточки, дрейф фоновых пятен, пульс статуса, hover-эффекты.
- Адаптив под мобильные (≤ 600px), поддержка `prefers-reduced-motion`.
- Иконка-монограмма `A` в `public/favicon.svg`.
- Мета-теги: `lang="ru"`, title, description, theme-color.
- Вики проекта: структура, правила ведения, глоссарий, обзор, стек, карта файлов, инструкции по запуску и dev-серверу, дизайн-система, журнал, ADR и шаблоны.

### Проверено

- `npm run build` — успешно, 17 модулей.
- Dev-сервер на `http://localhost:5173/` — HTTP 200.
