# Дизайн-система

## Настроение

Тёмная «ночная» тема, мягкие градиентные подсветки, стеклянная карточка. Ощущение: технологично, спокойно, без визуального шума.

## Цветовые токены

| Назначение | Значение | Где |
| --- | --- | --- |
| Фон страницы | `#070b10` | `.page`, `index.css` |
| Фон карточки (верх) | `rgba(19, 26, 36, 0.92)` | `.card` |
| Фон карточки (низ) | `rgba(10, 14, 20, 0.86)` | `.card` |
| Основной текст | `#e6edf3` | `:root` |
| Приглушённый текст | `#9fb1c4` / `#b9c7d6` | `.tagline`, `.about` |
| Акцент 1 (голубой) | `#38bdf8` / `#7dd3fc` | градиенты, иконки |
| Акцент 2 (фиолетовый) | `#a855f7` / `#c084fc` | градиенты |
| Статус «онлайн» | `#34d399` | `.dot` |
| Разделители | `rgba(255, 255, 255, 0.07)` | рамки, footer |

Градиент бренда: `linear-gradient(135deg, #38bdf8, #a855f7)`.

## Типографика

- Шрифт: системный стек `Segoe UI → Inter → system-ui → Helvetica Neue → Arial`.
- `h1`: `clamp(34px, 6vw, 46px)`, вес 700, трекинг `-0.02em`.
- Роль: 17px, вес 600, градиентный текст.
- Основной текст: 15.5px, интерлиньяж 1.7.
- Подписи: 11.5–12.5px, uppercase, трекинг `0.05em`.

## Компоненты

### Карточка `.card`

- ширина `min(760px, 100%)`;
- рамка `1px rgba(255,255,255,0.1)`;
- тень `0 30px 80px rgba(0,0,0,0.55)` + внутренний хайлайт сверху;
- `backdrop-filter: blur(18px)`;
- появление: `rise` 0.7s.

### Аватар `.avatar`

Круг 104px (мобильные 84px), градиентная рамка через `padding-box`/`border-box`, монограмма «А» градиентом, свечение `0 0 40px rgba(56,189,248,0.25)`.

### Бейджи навыков `.skills li`

Полупрозрачная голубая плашка, hover: приподнимание на 2px и усиление рамки.

### Строка контакта `.contact`

Иконка в плашке 38px, подпись + значение, стрелка справа. Hover: сдвиг вправо на 4px, стрелка подсвечивается.

### Фоновые пятна `.glow`

Два размытых круга (`blur(90px)`) — голубой слева сверху, фиолетовый справа снизу. Медленный дрейф 14s.

## Анимации

| Имя | Где | Длительность |
| --- | --- | --- |
| `rise` | появление карточки | 0.7s |
| `drift` | фоновые пятна | 14s, alternate |
| `pulse` | индикатор статуса | 2.4s |

Все переходы — 0.2s. При `prefers-reduced-motion: reduce` анимации и переходы отключаются.

## Веб-версия вики

Отдельный экран по маршруту `#/wiki`, стили изолированы в `src/wiki/WikiPage.css`.

| Элемент | Решение |
| --- | --- |
| Верхняя панель | sticky, `height: 64px`, полупрозрачный фон + `blur(14px)` |
| Сетка | `268px` меню + контент, максимум `1180px`, зазор 44px |
| Меню | липкое, активный пункт — голубая полоса слева и подсветка |
| Контент | колонка Markdown, ширина по остатку, `h1` 28–36px |
| Таблицы | скруглённая рамка, `overflow-x: auto`, uppercase-заголовки |
| Код | тёмные блоки с рамкой, `Cascadia Code` → `JetBrains Mono` → Consolas |
| Pager | две карточки «предыдущая / следующая» |
| Мобильные | ≤ 900px меню превращается в выдвижную панель + затемнение |

Цвета те же, что у визитки: фон `#070b10`, акценты `#38bdf8` / `#a855f7`, текст `#b9c7d6`.

## Адаптив

Единственный брейкпоинт — `max-width: 600px`:

- шапка складывается в колонку;
- уменьшаются аватар, отступы и радиусы;
- контакты остаются строкой, значение обрезается многоточием.

## Доступность

- Контраст текста на фоне ≥ 4.5:1 для основного текста.
- Интерактивные элементы — настоящие `<a>`, есть `aria-label` у навигации и списка навыков.
- Декоративные элементы скрыты через `aria-hidden="true"`.
- Страница не ломается при 320px ширины.
